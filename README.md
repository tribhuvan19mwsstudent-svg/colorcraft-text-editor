# Textora - Beginner Text Editor

A simple text editor project made using basic HTML, CSS and JavaScript.

## Features
- Type text in the text area.
- Change the background colour using colour buttons.
- Change the text colour using colour buttons.
- Change the font family using a dropdown list.
- Download the written text as a text file.

## How to run
Open `index.html` in a web browser.

## Technologies
HTML, CSS and JavaScript.
